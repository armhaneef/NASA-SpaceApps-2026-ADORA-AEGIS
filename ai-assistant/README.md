# AI assistant

This module will provide a bounded explanation layer for prototype data and
model outputs. It is not a diagnostic system and must not present generated
content as medical advice.

**Expected inputs:** Documented sensor records and/or explicitly labeled model
outputs, along with relevant approved knowledge-base material.

**Expected outputs:** Plain-language explanations that preserve uncertainty,
identify synthetic or prototype inputs, and follow the safety rules developed
by the team.

**Status:** Structure only. No AI provider, prompts, or knowledge base is
configured.
